# Catholic Commerce Agent IA

Projeto de estudo desenvolvido durante a fase de nivelamento de um projeto de extensão acadêmica.

O objetivo é desenvolver habilidades em Inteligência Artificial, explorar integrações com ferramentas externas e aprender na prática, preparando-se para aplicar esses conhecimentos futuramente em um squad de IA.

## Funcionalidades
- Integração com Excel.
- Estudo de automação de processos.
- Desenvolvimento de um agente de IA para simulação de atendimento e vendas.

## Status
Em desenvolvimento.

**Observação:** Projeto exclusivamente educacional, voltado ao aprendizado e ao desenvolvimento de habilidades.
